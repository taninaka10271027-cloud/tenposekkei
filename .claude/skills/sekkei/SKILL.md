# sekkei — 店舗電気設備 作図スキル

作図ルールはリポジトリの `CLAUDE.md` に書いてある。必ず先に読み、すべて守ること
(特に、水回り・屋外の別回路、条数表記、交差と平行、1/8点からの引き出し、記号の統一)。

## 入力
- 1F・2F の建築平面 DXF (R12・cp932 のことが多い。ezdxf で読めない場合は `scripts/r12.py` で読む)
- 照明プラン PDF (メーカーの器具表と配置)
- 空調プラン PDF (室内機・室外機の機種と位置)
- 換気機種選定書 (Excel など。機種・風量・ダクト径)
- 条件: 天井高、階高、道路面(延焼ライン)、取付高さの特記、回路の指定

## 手順
1. **入力の読み取り・照合**
   - 照明・空調・換気の位置を平面図の座標に変換する。
   - 既存のプロットと各プランを照合し、食い違いはチェック欄(雲マーク+注記)で図面に残す。
2. **機器と回路の定義**
   - `data.py` に照明器具表、器具・スイッチ・コンセント・換気扇・空調機の座標と回路を書く。
   - 回路割りでは、水回り・屋外を居室と分ける。厨房・空調・EV は専用回路、非常灯・誘導灯も専用回路にする。
   - 点滅区分の英字を、器具・換気扇・スイッチで一致させる。
3. **プロット図** (`gen_plot.py`): JIS C 0303 の記号を描き、取付高さを凡例に書く。
4. **配線図** (`gen_wire.py` / `wire2.py`)
   - 回路ごとに木構造を作る: スイッチボックス、JB、器具、立上り。
   - ネットを追跡して条数を自動で出す: L、N、スイッチ返り線、3路の渡り線。
   - 経路の候補 (L字・Z字、1/8点のポート付き) を採点し、引き直しをかけてから、平行線を100離す。
     - 採点項目: 交差、記号貫通、平行、長さ、曲げ数、出口の重複。
   - 交差は片側を切り、斜線(条数)は切り欠きや記号を避けて置く。
   - 電源線とスイッチ線が混在する区間は、2本に分けて描く。
5. **盤結線図・幹線・負荷計算** (`gen_sched.py`)
   - L-1・P-1 盤の主幹と分岐を決める。
   - 幹線は CV のサイズを電圧降下表付きで選ぶ。
   - 凡例、照明器具表、機器姿図もここで作る。
6. **換気・空調** (`gen_mech.py`)
   - ダクト径は選定書による。延焼ライン面のフードは FD 付きにする。
   - 冷媒・ドレン配管と内外連絡線を描く。
7. **一括出力** (`gen_all.py`)
   - DXF を10枚出力する: E-01〜E-08、M-01、M-02。
   - 確認用 PNG と、PDF にまとめる用の画像も作る。
8. **検査**
   - `chk2.py`: 切り欠きのない交差、100未満の平行 → 0 にする。
   - `chk_pen.py`: 記号貫通 → できるだけ 0 にする。
   - `count_x.py`: 交差の数 → できるだけ減らす。
   - プレビューを目視し、混み合う箇所は JB 位置と経路を調整する。
9. **拾い出し表** (`takeoff.py` → `build_xlsx.py`)
   - 配線図と同じルートで数量を出す: 平面長 + 立下り・立上り (天井高・階高・取付高さから)。
   - シートは設備ごとに分ける: 幹線動力 / 電灯コンセント / 照明器具 / 換気 / 空調 / 明細。
   - 出力後は数式を再計算し、エラー0を確認する。
10. **サブエージェント査図**
    - 図面と入力資料を突き合わせて、次の点を添削させる: 回路、条数、交差、記号の統一、別回路ルール。
    - 指摘を直してから納品する。

## スクリプトの使い方
`scripts/` は案件「樽屋」で使った参考実装。

- `data.py` は案件ごとに書き換える。
- `gen_wire.py` の固定ルート (動力・ホームラン・立上り) と障害物も、案件ごとに直す。

```bash
export SEKKEI_WORK=/path/to/work      # in/1F.dxf, in/2F.dxf を置く。prev/ にプレビューが出る
export SEKKEI_OUT=/path/to/work/out   # DXF・Excel の出力先
python3 scripts/gen_all.py
python3 scripts/chk2.py; python3 scripts/chk_pen.py; python3 scripts/count_x.py
python3 scripts/build_xlsx.py
```

必要なもの: Python3、ezdxf、matplotlib、openpyxl、Pillow
