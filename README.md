## 設計条件

- 天井高 CH=2,400、スイッチ FL+1,300、コンセント FL+300（特記なき限り）
- 分電盤：店舗用 L-1（倉庫内壁）、事務所用 L-2（事務所内 階段側壁）
- 幹線：店舗 ニュースラットケーブル 14sq×3、事務所 ニュースラットケーブル 8sq×3（引込点は別途）
- 電灯回路（店舗）：L1-1 水回り（厨房・便所）／L1-2 その他（客席・座敷・倉庫）
- 厨房専用回路 5 回路（L1-7〜11、機器未定のため 100V×3・200V×2 で仮設定）
- 2階予備 6 回路（L1-13〜18、店舗分電盤に確保し階段部で立上り）
- 照明：店舗はダウンライト（床面 200lx）、倉庫・厨房・事務所はベースライト 6,900lm（光束法で台数算定）
- コンセント：一般は 1 室 2 箇所程度、事務所は OA 専用 4 回路（L2-3〜6）
- 弱電設備は対象外
- 配線交差部は**縦方向（図面 Y 方向）の配線を切断**して表示（統一）
- 同一室に複数の点滅区分がある場合、スイッチと器具に ア・イ… を傍記

### 質疑で確定した事項

- 厨房：中央カウンター（5,850×800）南側〜棚の範囲
- 中央の部屋（1000×6000 テーブル 2 台）：店舗の座敷（客席）
- 2階予備回路：店舗分電盤 L-1 から
- 分電盤位置：店舗＝倉庫内壁、事務所＝事務所内壁

### 設計上の仮定（要確認）

- 事務所の出入口は東側の引違い（南寄り）と仮定し、スイッチをその脇に配置
- 便所の温水洗浄便座は貯湯式 700VA×2 と想定（L1-6）
- 活イケス（屋外）用に防雨形専用コンセント（L1-12）を追加提案
- 照明率は反射率 70/50/10 の一般値。器具決定後にメーカー照明率表で再確認
- 2階予備回路の容量は未計上。2階負荷確定時に主幹・幹線を再検討

## 再生成

```bash
pip install ezdxf matplotlib openpyxl pymupdf
python scripts/make_elec_plan.py        # 平面図 DXF + quantities.json
python scripts/make_panel_sheet.py      # 分電盤結線図・照度計算表 DXF
python scripts/make_quantity_xlsx.py    # 数量表 xlsx
python scripts/render_dxf.py output/電灯コンセント設備平面図.dxf output/電灯コンセント設備平面図.pdf --paper 420 297 --scale 50 --color
```

建築下図は `source/heimenzu02.pdf`（ベクタ）の座標を実寸換算して取り込み（`source/heimenzu02_vec.json`）。
